# Clark County, OH

**Source:** SOS-hosted Ohio ENR, election ID 20 (Nov 3, 2026 general).

- Summary XML: https://liveresults.boe.ohio.gov/ENR/clarkohenr/20/summary_20.xml
- Summary CSV: https://liveresults.boe.ohio.gov/ENR/clarkohenr/20/summary_20.csv

Vote types in the feed: Early Voting, Absentee Ballots, Election Day, Provisional.

These files sit behind a Cloudflare Turnstile check. The scraper reads them
through the Chrome window opened by `tools/sos_chrome.sh`
(`common/sos_browser.py`). Generated by `tools/make_sos_scrapers.py`.
