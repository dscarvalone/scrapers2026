# Stark County, OH

**Source:** SOS-hosted Ohio ENR, election ID 14 (Nov 3, 2026 general).

- Summary XML: https://liveresults.boe.ohio.gov/ENR/starkohenr/14/summary_14.xml
- Summary CSV: https://liveresults.boe.ohio.gov/ENR/starkohenr/14/summary_14.csv

Vote types in the feed: Early In Person Votes, Voteby Mail Votes, Election Day, Provisional.

These files sit behind a Cloudflare Turnstile check. The scraper reads them
through the Chrome window opened by `tools/sos_chrome.sh`
(`common/sos_browser.py`). Generated by `tools/make_sos_scrapers.py`.
